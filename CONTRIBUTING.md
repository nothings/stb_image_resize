Contributions Welcome
=====================

Issues and bugfixes are both welcome. No need for PRs, as I rewrite everything that comes in.

This repo is fairly mature - expect mostly just the occasional bug fix in future. 

### Responsiveness

General priority order is:

* Crashes/security issues
* Warnings
* Enhancements (new features, performance improvement, etc)
* New archtectures - unlikely, since we will only add new architectures if I can get the hardware and they are in wide use.


AI AND LLM ARE TOLERATED
========================

This project is a AI tolerant, but wary repo. As I find AI to be useful for tracking down and fuzzing the types of bugs that a big mature codebase like this encounters, I will accept AI bug reports as well. Since I rewrite and retest any submissions, just supply the AI summaries, don't need to send AI PRs or AI generated fixes.
